Jarvis for Claude Code on the web

Made by Nur Al Mahtab

In Jarvis: Settings → Claude Code → switch on Claude Code on the web, then copy the pairing code shown.

What leaves your browser
  • Only a state (working, waiting for you, finished) and a fixed short label such as "Working".
  • It goes only to Jarvis on this PC (127.0.0.1), never over the internet.
  • Never your messages, code, file names or the page title.
  • Approving a permission request still happens in the browser: Jarvis only tells you it is waiting.
If the notch says "unavailable", claude.ai may have changed its layout: update selectors.js.
